# Pretty Vacant website

Statische site voor GitHub Pages. Alleen HTML, CSS en een beetje JavaScript.

## Wat pas je aan?
Bijna alles staat in **gegevens.js**: tourdata, video's, foto's, riders en contactgegevens.
Open dat bestand op GitHub, klik op het potloodje, pas aan en klik op "Commit changes".

- Foto's: zet ze in de map `fotos/` en noem ze in `gegevens.js`.
- Riders: zet de PDF's in de map `riders/` en vul de bestandsnaam in bij `RIDERS`.
- Video's: vul het YouTube-id in bij `VIDEOS`, of zet een eigen .mp4 met plaatje in de map `video/` en noem die bij `VIDEOS`.

## Bestanden
- `index.html` de pagina
- `style.css` de vormgeving
- `site.js` de logica (hier hoef je niet aan te komen)
- `gegevens.js` de inhoud
- `img/` logo, Union Jack en deelbeeld voor social media
